## What is Movian?

Movian is an open-source media center platform that allows users to browse and play media content from various sources. With its powerful plugin system, developers can extend Movian's functionality to support new content providers, customize the user interface, and add innovative features.

## Plugin Types

Movian supports several types of plugins:

- **Content Provider Plugins** - Add support for new streaming services and media sources
- **UI Plugins** - Customize the user interface and create new themes
- **Utility Plugins** - Add helper functions and tools
- **Integration Plugins** - Connect with external services and APIs
