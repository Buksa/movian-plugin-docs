# Development Environment Setup

This guide will help you set up your development environment for creating Movian plugins and skins.

## Required Tools

- Text editor or IDE (VS Code, Sublime Text, etc.)
- Movian media center installed
- Git for version control

## Directory Structure

Create a workspace directory for your plugin development:

```
movian-plugins/
├── my-plugin/
│   ├── plugin.json
│   ├── main.js
│   └── assets/
└── my-skin/
    ├── views/
    └── assets/
```
